記事

　

商品を探す

「候補を自動で選ぶ」を押すと、楽天を60件ぶん調べて、同じ商品をまとめたうえで 口コミ数・評価・価格帯のばらつきから10点前後に絞ります。そこから6〜7点を選んでください。

用品ばかり出て本体が出てこないときは、除外キーワードを入れてください。 例：「うさぎ トイレ」で砂やシーツが並ぶなら 砂 シーツ マット 消臭 を除外します。

この記事に載せる商品 0点

価格帯とサイズが散るように選ぶと、比較記事として読みやすくなります。

登録すると、本文に貼るための記法（{{product:…}}）が発行されます。

口コミを読み込む

ボタンを押したときだけ取得します。取得したものは保存され、二度目は取りにいきません。 楽天のページに連続でアクセスしないよう、1件ごとに間隔を空けます。 記事には本文をそのまま載せず、傾向の要約として書きます。

執筆用の材料をそろえる

スタイルガイド・商品情報・口コミの傾向をまとめたファイルを書き出します。

Claude に書いてもらう

実体験の部分は書かせません。【　】が置かれるので、あとでご自身で埋めてください。

結果

あなたが書く場所

ここはAIに書かせません。期間・回数・具体的な出来事を入れると、読者にとって新しい情報になります。

本文に入れる画像

選ぶと自動で幅1200pxに縮めて保存します。 ご自身で撮った写真や、自作の図解を入れてください。 フリー素材のうさぎ写真は、読者が「この人のうさぎ」と受け取ってしまうため避けます。

本文

公開されたときとまったく同じ見た目で表示します。
ドラッグで選ぶとマーカーを引けます。ダブルクリックすると、その段落をその場で書き換えられます。

コピペチェック

集めた口コミがそのまま本文に入っていないか、自分の別の記事と同じ言い回しになっていないかを調べます。 外部サイトとの照合は、確認用のフレーズを出すところまでです（理由は結果の下に書いています）。

自動チェック

スタイルガイドの決まりごと、誇大表現、実体験の付け方（ステマ規制）を自動で確認します。

日本語で書けます。送るときに画像生成向けの英語へ自動で直します。 うさぎそのものは描かせないでください。 実在しないうさぎを実写のように見せると、実体験で書いているこのサイトでは誤解を招きます。 牧草・ケージ・食器・部屋の様子など、ものや場所を描くのが向いています。

動画
fal.ai で短い動画を作ります


  

    
動画をつくる

    
設定画面で fal.ai の API キーを入れると使えるようになります。

    

      
      
    

    
    

      
      
    

    

      

    
できあがるまで 1〜5 分ほどかかります。動画は toco-app/videos/ に保存されます（GitHub には送りません）。

  


  

    
できた動画

    

  


  

    
動く LINE スタンプ ① シートから動画をつくる

    
8体のイラストを横4×縦2に並べた1枚の画像を用意します。背景は緑一色（#00FF00）にしておくと、あとで透過にできます。
      各イラストはマスの中央に置き、マスの端から少し余白をとってください。

    

      
      
    

    
    

      
      
    

    

    
MiniMax H3 Max Turbo（画像→動画）を使います。できた動画は上の「できた動画」に並びます。

  


  

    
動く LINE スタンプ ② 動画からスタンプを切り出す

    

      
      
    

    

      
      
      
    

    

      
      
      
    

    

      
      
      
    

    

    
1ループの長さは「再生時間 ÷ ループ回数」です。標準（4秒・2回）なら2秒の動きが2回流れます。
      動きの速さは「使う区間の長さ」と「1ループの長さ」をそろえると実物どおりになります。区間を0〜2秒にしてあるのはこのためです。区間だけ長くすると早送りになります。
      最後のコマを先頭に回してあるので、止まったときは動きの終わりのポーズで止まります。

  


  

    
動く LINE スタンプ ③ 選んで申請用 zip にする

    
申請するスタンプにチェックを入れて「zip にする」を押します。チェックした順に 01.png、02.png … と番号が付き、
      最初の1つから main.png（240×240）と tab.png（96×74）を作ります。LINE の1セットは 8・16・24 個です。

    

      
      

    

    

  







  
設定


  

    
楽天ウェブサービス

    
商品の検索・スペック・画像に使います。無料で取得できます。

    

      
      
    

    

      
      

    
鍵は toco-app/data/secrets.json にだけ保存され、GitHubには送られません。

  


  

    
fal.ai（動画生成）

    
「動画」画面で使います。fal.ai のダッシュボードで発行したキーを入れてください。生成のたびに fal 側で課金されます。

    

      
    

    

      

  


  

    
もしもアフィリエイト

    
商品カードのリンクに使います。もしもには公開APIが無いので、
      管理画面で発行したリンクを1本貼っていただければ、そこから型を読み取ります。

    

    
    

      商品は何でも構いません。リンクの型さえ分かれば十分です。

  


  

    
Claude Code

    
記事の下書きを書いてもらうのに使います。サブスクリプションで動くため、APIの従量課金は発生しません。

    
    

      

  


  

    
接続元のIPアドレス

    
APIの登録でIPの申告が必要なときに使います。
