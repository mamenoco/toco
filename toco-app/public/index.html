記事ネタ

記事

　

楽天で商品を探す

レビュー件数の多い順に並びます。持ちもの台帳にある商品には印が付きます。

この記事に載せる商品 0点

価格帯とサイズが散るように選ぶと、比較記事として読みやすくなります。

登録すると、本文に貼るための記法（{{product:…}}）が発行されます。

口コミを読み込む

ボタンを押したときだけ取得します。取得したものは保存され、二度目は取りにいきません。 記事には本文をそのまま載せず、傾向の要約として書きます。

執筆用の材料をそろえる

スタイルガイド・商品情報・口コミの傾向をまとめたファイルを書き出します。

Claude に書いてもらう

実体験の部分は書かせません。【　】が置かれるので、あとでご自身で埋めてください。

結果

あなたが書く場所

ここはAIに書かせません。期間・回数・具体的な出来事を入れると、読者にとって新しい情報になります。

楽天ウェブサービス

    
商品の検索・スペック・画像に使います。無料で取得できます。

    

      
      
    

    

      
      

    
鍵は toco-app/data/secrets.json にだけ保存され、GitHubには送られません。

  


  

    
もしもアフィリエイト

    
商品カードのリンクに使います。もしもには公開APIが無いので、
      管理画面で発行したリンクを1本貼っていただければ、そこから型を読み取ります。

    

    
    

      商品は何でも構いません。リンクの型さえ分かれば十分です。

  


  

    
Claude Code

    
記事の下書きを書いてもらうのに使います。サブスクリプションで動くため、APIの従量課金は発生しません。
