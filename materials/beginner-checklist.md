# 「はじめての方へ」記事 素材リスト

初めてうさぎを迎える方向け。準備に必要な知識と物品の洗い出し。
公開先想定：https://toco-to.com/beginner/ （※現在404。ヘッダー・サイドバーからリンク済みなので優先度高）

## A. 迎える前に知っておきたい知識

### A-1. うさぎという動物の基礎

| 項目 | 内容 | 記事での扱い |
|---|---|---|
| 寿命 | 一般に7〜10年、飼育環境がよければ10年超も | 「思ったより長い」＝覚悟の話として冒頭に |
| 食性 | 完全草食。主食は牧草（繊維質） | 牧草記事への導線 |
| 歯 | 生涯伸び続ける（常生歯）。繊維質をすりつぶして摩耗させる | 牧草・かじり木の必要性の根拠 |
| 盲腸便 | 夜間などに出す柔らかい便を食べ直して栄養を吸収する | 「食糞は異常ではない」と安心させる |
| 鳴かない | 声帯が未発達で鳴き声をほぼ出さない | 集合住宅向けのメリット |
| 感情表現 | 足ダン・鼻鳴らし・ペロペロなど体で示す | コラム化の余地 |
| 活動時間 | 薄明薄暮性（明け方と夕方に活発） | 生活リズムの説明に |
| 抱っこ | 苦手な個体が多い。骨格が体重比で軽く、暴れて落下すると骨折しやすい | 安全面の注意として必須 |
| 飼育頭数 | 縄張り意識が強く単独飼育が基本。多頭は要別ケージ | 初心者には1羽を推奨 |

### A-2. 飼育環境の条件

- 適温の目安：**18〜24℃前後**、湿度40〜60%。とくに**暑さと多湿に弱い**
  → 夏はエアコン常時稼働が前提。冬はペットヒーター。電気代の話に触れると親切
- ケージの置き場所：直射日光・エアコンの風が直接当たらない／人の出入りが激しすぎない／床から少し上げる
- 騒音・振動を避ける（テレビの真横、洗濯機のそばはNG）
- 賃貸なら**ペット可か、うさぎが対象に含まれるか**を契約書で確認
- 部屋んぽ（部屋での運動）スペースの確保
- におい：糞尿の管理と換気。うさぎ自体はほぼ無臭

### A-3. お金の話

- 初期費用の目安：**生体費のほかに3〜5万円程度**（ケージ一式＋衛生用品）
- 月々の目安：牧草・ペレット・トイレ砂・消耗品で3,000〜5,000円程度
- 医療費：うさぎは**ペット保険の選択肢が犬猫より少ない**。加入は迎えてすぐが有利
- 想定外の出費：うっ滞での通院、歯のトラブル、避妊手術（メス、10万円前後）、夏場の電気代
  ※金額はすべて幅を持たせて書く。断定しない

### A-4. 病院探し ★迎える前にやることとして強調

- **うさぎを診られる動物病院は限られる**。犬猫専門の病院が多い
- 「エキゾチックアニマル対応」「うさぎ診療可」で事前に探し、車で行ける距離か確認
- 夜間・救急の対応先も調べておく
- 初回健康診断の予約を迎える前に取っておく

### A-5. 迎え方の選択肢

- ペットショップ／ブリーダー／里親・保護うさぎ ── それぞれのメリットと注意点
- 主な品種：ネザーランドドワーフ、ホーランドロップ、ミニレッキス、ライオンヘッド、アメリカンファジーロップ、ミニウサギ
  → 大きさ・毛の長さ（＝お手入れの手間）・性格の傾向で選ぶ
- 性別の違い：メスは子宮疾患のリスクがあり避妊手術の検討が必要／オスはスプレー行動
- お迎え時の健康チェック：目やに・鼻水・耳の汚れ・お尻の汚れ・毛づや・食欲・便の大きさと量
- 生後どのくらいの子を迎えるか（離乳直後の幼齢個体は体調を崩しやすい）

### A-6. 心構え

- 留守番は1泊が限界。長期の旅行はペットホテル／預け先が必要
- 最初の1週間はかまいすぎない
- なつき方は犬猫と違う（膝に乗る子ばかりではない）
- 家族全員の同意とアレルギーの確認（うさぎ・牧草どちらにも反応が出ることがある）

## C. 迎えた当日〜1週間

1. **当日**：ケージに入れたらそっとしておく。かまわない、抱っこしない
2. **1〜2日目**：食べているか・便が出ているかだけ確認。牧草とペレットは前の環境と同じものを継続
3. **3日目〜**：手からおやつ、名前を呼ぶ程度の接触
4. **1週間**：落ち着いたら動物病院で初回健診
5. **部屋んぽ開始**は環境に慣れてから（2週間目以降が目安）

★ 環境が変わると食欲が落ちやすい。**24時間食べない・便が出ない場合はすぐ病院**（うっ滞の可能性）

## D. やってはいけないこと・危険なもの

- 与えてはいけない食べ物：ネギ類、チョコレート、アボカド、じゃがいもの芽、生の豆、人間のお菓子全般
- 危険な植物：観葉植物の多く（ポトス、ユリ、アサガオなど）。部屋んぽ範囲から撤去
- 電気コード・コンセントのかじり ← 感電・火災事故。**コードカバー必須**
- 隙間への侵入、家具の裏、扉の開閉時の挟み込み
- 高い場所からの落下（ソファ・机の上に乗せない）
- 水浴び・シャンプー（体力を消耗する。原則不要）
- 暑い車内・直射日光
- 犬猫用の薬・フードの流用
