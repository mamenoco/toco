tocoとくらし WordPressテーマ 1.0.0

このテーマは、既存の投稿・固定ページ・画像を削除せず、サイトの外観だけを変更します。

導入後の推奨設定
1. 外観 → メニューで「メインメニュー」と「フッターメニュー」を割り当てる
2. 各記事にアイキャッチ画像を設定する
3. カテゴリーのスラッグを必要に応じて food / house / toy / care / life / column に設定する
4. 「はじめての方へ」と「お問い合わせ」の固定ページを作成する

注意
- テーマ有効化だけでは投稿や画像は削除されません。
- 不要記事の削除は、残す記事を確認してから個別に行ってください。
