# うさぎが震えるのはなぜ？様子見でいい震えと病院に行く目安

※本記事にはアフィリエイト広告が含まれます。

ケージをのぞいたとき、うさぎの体が小刻みに震えている。どこか痛いのか、寒いだけなのか、見ただけでは分からないまま様子を見ていていいのか迷ってしまいますよね。震えの多くは、==熱を作るための震えか、緊張がゆるむまでの震え==で、環境を整えれば数分から十数分でおさまります。ただし、耳のつけ根まで冷たい・うんちが出ていない・歯ぎしりをしている、このどれかが重なっているときは急いだほうがいい震えです。

この記事では、震え方ごとの早見表と、様子を見ていい震えの見分け方、動物病院へ連絡する目安、震えと一緒に出ていたら疑いたい病気、今すぐ家でできることをまとめます。今まさに震えているなら、下の表から先に見てみてください。

## うさぎが震える理由は、大きく3つに分かれます

震えの原因は、体を温めるための震え・気持ちが動いたときの震え・痛みや病気による震えの3つに分けると見当がつけやすくなります。見るべきところは震えの強さではなく、==震え以外に何が一緒に出ているか==です。

| 震えの様子 | 考えられること | まずすること |
|---|---|---|
| 体を丸めて小刻みに震える | 寒さ | 室温を測って20度前後へ |
| 耳も体も冷たく動かない | 体温の低下 | 温めながら病院へ連絡 |
| 抱っこや来客の直後に震える | 緊張・こわさ | 静かな場所に戻す |
| 眠っていてぴくぴくする | 浅い眠り | そのままで大丈夫 |
| ブルッと一度だけ身震い | 毛づくろいの仕上げ | そのままで大丈夫 |
| 鼻を速く動かし息が荒い | 暑さ | 涼しい場所へ移して連絡 |
| うずくまって歯ぎしり | 痛み・うっ滞 | すぐ動物病院へ |
| 頭が傾く・よろける | 斜頸 | すぐ動物病院へ |

同じ震えでも、立ち上がって牧草を食べにいく子と、うずくまったまま動かない子では意味がまったく違います。食べる・動く・うんちが出ている、この3つがそろっていれば、まずは環境から見ていきましょう。

## 体調が悪くなくても震えることはあります

病気ではない震えは、よくあることです。うさぎは体温の調節も気持ちの表し方も体の動きに出るので、健康な子でも震える場面はいくつもありますよ。

### 寒くて熱を作っているとき

**震えは寒さのサインとしては進んだ段階です**

筋肉を細かく動かして熱を作っている状態で、部屋の温度が体にとって足りていないことを表しています。==うさぎが過ごしやすい室温は18〜24度くらいが目安==とされているので、まず温度計の数字を確かめてみてください。

このときの震えは、暖かい場所に移してしばらくすると引いていきます。10〜15分ほどたっても変わらない、あるいは耳のつけ根まで冷たいままなら、寒さだけの話ではなくなっています。

### 緊張やこわさがほどけていないとき

**抱っこや移動のあとの震えは落ち着けば止まります**

動物病院からの帰り、来客のあと、掃除機をかけた直後。音やにおいの刺激が強かったあとに、小さく震えながら固まっている子は多いです。うさぎにとっては逃げ場を探している状態なので、追いかけて抱き上げるより、静かな場所に戻して離れるほうが早くおさまります。

抱っこのときだけ震えるなら、嫌われているわけではなく、足が浮く姿勢そのものがこわいことが多いです。抱き方のコツは{{link:rabbit-holding|うさぎの抱っこのしかた}}で紹介しています。

### 興奮や発情で体がふるえているとき

**発情期は後ろ足や体をふるわせる子がいます**

鼻をブーブー鳴らしながら足をふるわせる、おしりを小さく震わせる。こうした震えは、春や秋の発情が強く出る時期に目立ちます。食欲も動きも変わらないなら、季節が過ぎれば落ち着いていきますよ。

ほかにも、眠りが浅いときのぴくぴくした動きや、毛づくろいの最後にブルッと一度だけ体を振る動き。どちらも震えとは別のもので、心配はいりません。くわしい見分け方は{{link:rabbit-mating|うさぎの発情期の行動}}にまとめました。

## すぐ動物病院に連絡したい震えの目安

次のどれかが震えと一緒に出ているときは、温めて様子を見るのではなく、先に動物病院へ連絡してください。うさぎは弱っているところを隠すので、==震えが見た目に出るころには、すでに我慢している段階==だと考えたほうが安全です。

- 半日（12時間）以上うんちが出ていない、または極端に小さい
- 牧草にもペレットにも口をつけない
- うずくまったまま歯ぎしりをしている、呼吸が速い
- 暖かい場所に移して30分たっても震えが止まらない
- 耳も体もひんやりして、呼びかけへの反応が鈍い
- 頭が片側に傾く、同じ方向にぐるぐる回る
- よだれで口のまわりやあごが濡れている

とくに、うんちが出ていない震えは急ぎたいところ。うさぎは半日食べないだけでおなかの動きが落ちるので、朝気づいたなら、その日のうちに連絡しておくと安心です。気になる症状があるときは、自己判断せず動物病院で相談しましょう。

夜間や休診日に慌てないよう、今のうちに近くの救急対応の病院を調べておくのがおすすめです。探し方のポイントは{{link:rabbit-vet|うさぎの動物病院の探し方}}にまとめています。

## 震えと一緒に出ていたら疑いたい病気

震え方だけで病名は決まりませんが、震えとして表に出やすい病気はいくつかあります。どれも早いほうが選べる手が多いとされているので、心当たりのある様子があれば受診の判断材料にしてみてください。

おなかの動きが止まる{{link:rabbit-stasis|うっ滞}}は、痛みから体を震わせることがあります。食欲とうんちが同時に落ちるのが特徴で、おなかを触られるのを嫌がる子もいます。

歯のかみ合わせが崩れる{{link:rabbit-teeth|不正咬合}}でも、痛みで震えたり、よだれが出たりします。牧草を食べる量が落ちて、やわらかいものばかり選ぶようになったときは口の中を疑ってみましょう。

頭が傾いてよろける斜頸は、エンセファリトゾーンという寄生虫や、中耳の炎症が関わっているとされています。体のバランスが取れずに震えているように見えることもあるので、首の傾きが見えたら様子見はしないでください。

夏場は暑さも原因になります。うさぎは汗をかけないので、室温が28度を超えるような環境では体に熱がこもり、呼吸を速くしながら体を小さく震わせることがあります。

植物や人の食べ物を口にしたあとの震えも要注意です。玄関やリビングに置いた鉢植えをかじったあとに震えが出たなら、何をどのくらい食べたかを伝えられるように、残りを持って受診してください。危ないものは{{link:rabbit-nogo-food|うさぎが食べてはいけないもの一覧}}で確かめられます。

## 震えに気づいたとき、家でまずすること

食べる・動く・うんちが出ている、この3つがそろっているなら、環境を順番に確かめていきます。やってはいけないのは、==体をこすったりドライヤーを当てたりして急に温めること==。皮膚を痛めるうえ、うさぎが逃げられずに余計に力が入ります。

### 1. ケージの高さで室温を測る

人が立って感じる温度と、床に近い場所の温度は、同じ部屋でも数度違います。エアコンの設定だけで判断せず、ケージの横に温湿度計を置いて、うさぎがいる高さの数字を見てみてください。湿度は40〜60%が目安です。

留守のあいだに何度まで下がったかを知りたいなら、最高と最低を記録してくれるタイプが便利。選び方は{{link:rabbit-thermometer|うさぎの温湿度計のおすすめ}}で紹介しています。

### 2. すきま風と床からの冷えをふさぐ

窓際や玄関の近くにケージがあると、暖房をつけていても足元だけ冷えます。ケージの背面を壁につける、窓側に段ボールを立てる。それだけでも体感は変わってくれますよ。

フローリングに直置きしているケージは、下から熱が抜けていきます。マットを1枚はさんで、床との間に空気の層を作っておきましょう。

### 3. ケージの半分だけを温める

温めるときのコツは、ケージ全体ではなく一角だけにすることです。暑く感じたときにうさぎが自分で離れられる場所を残しておけば、温めすぎを避けられます。

## よくある質問

### 震えはどのくらいで止まれば大丈夫ですか

寒さや緊張による震えなら、環境を整えてから10〜15分ほどでおさまっていくことが多いです。30分たっても止まらない、牧草に口をつけない、という場合は様子見をやめて動物病院へ連絡してください。

### 子うさぎやシニアのうさぎは震えやすいですか

体温を保つ力に差があるので、生後3か月くらいまでの子と、7歳を超えたあたりからは寒さに弱くなりやすいです。同じ室温でも感じ方が違うため、数字だけで決めず、丸まって動かない時間が増えていないかをあわせて見ていきましょう。

### 夏なのに震えているのはなぜですか

エアコンの風が直接当たっていたり、設定温度が低すぎて冷えていることがあります。風向きを変える、ケージの位置をずらす、といった調整で変わるので、夏も寒さの可能性は残しておきましょう。冬の運転のしかたは{{link:rabbit-winter-aircon|エアコンのつけっぱなし}}の記事で紹介しています。

### 震えているとき、毛布で包んでもいいですか

体に巻きつける形はおすすめしません。うさぎが暑いと感じたときに自分で抜け出せる状態にしておきたいので、ケージにかける・潜れる場所に敷く、という使い方にとどめましょう。かじって食べてしまう子もいるため、布を使うときは目の届く時間だけにしてください。

## 震え方を読み分けて、落ち着いて向き合おう

うさぎの震えは、寒さ・緊張・痛みのどれかに当てはまることが多く、震え以外に出ている様子を見れば見当がつきます。食べている・動いている・うんちが出ている。この3つがそろっているなら、まず室温とすきま風から確かめていきましょう。

逆に、うんちが止まっている、歯ぎしりをしている、頭が傾いている。こうした様子が重なったときは、温める前に動物病院へ連絡してください。判断の線引きを先に決めておけば、震えに気づいた朝も慌てずに動けます。
