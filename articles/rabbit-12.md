# うさぎが撫でられて喜ぶ部位は？嫌がる場所と撫で方のコツ

※本記事にはアフィリエイト広告が含まれます。

部屋んぽ中に足元まで来たので背中を撫でたら、さっと逃げられてしまった。嫌われたのかと思いながら、次はどこを触ればいいのか分からなくなってしまいますよね。うさぎが撫でられて心地よいのは==おでこ・鼻の付け根・耳の付け根といった顔まわり==で、自分の舌が届かない場所とほぼ重なります。反対に、おしり・しっぽ・おなか・足先は、ほとんどの子が触られるのを好みません。

この記事では、喜ぶ部位と嫌がる部位の分かれ目、撫でているときに出るサインの見分け方、逃げる子に手を覚えてもらう順番をまとめました。急に撫でられるのを嫌がるようになったときに、動物病院で相談したい目安もあわせて紹介します。

## 喜ぶ部位は、自分で毛づくろいできない場所です

うさぎが撫でられて心地よいと感じるのは、==自分の舌や前足が届かない場所==です。うさぎは仲間同士で顔や頭のまわりをなめ合って毛づくろいをします。人の手も、その相手の代わりとして受け入れているわけですね。

逆に言えば、自分で毎日きれいにできる場所は、人に触られる必要がありません。おしりやしっぽ、後ろ足は自分で届きます。そこに手が伸びると、毛づくろいではなく、捕まえられる動きとして受け取られます。

部位ごとの好みは、だいたい次のように分かれます。

| 部位 | 好む子 | 覚えておきたいこと |
|---|---|---|
| おでこ・目の上 | 多い | 最初に触る場所に向く |
| 鼻の付け根 | 多い | 指1本で軽く |
| ほほ・耳の付け根 | 多い | 慣れてから |
| 背中の前半分 | 分かれる | 毛並みに沿って |
| あご下 | 分かれる | 嫌う子もいる |
| おしり・しっぽ | 少ない | 自分で届く場所 |
| おなか | ごく少ない | 仰向けにしない |
| 足先・耳の中 | 少ない | 健康チェックだけ |

好みには個体差があるので、表のとおりにいかない子もいます。初対面の場所をいきなり触らず、1か所ずつ試していくのが近道です。

## 喜ぶ部位の撫で方

部位が分かっても、手の出し方を間違えると逃げてしまいます。ここは触る順番と力加減で変わるところ。

### おでこから後頭部


![](/assets/img/rabbit-12/hitai.jpg)


**最初に触るならおでこが一番通りやすいです**

目と目のあいだから後頭部に向かって、毛並みに沿って指を滑らせます。力は、皮膚が少し動くくらいでじゅうぶん。手のひら全体をかぶせるより、==指2本で額の中心をなぞる==ほうが受け入れられやすいですよ。

気をつけたいのは、手を真上から下ろすことです。うさぎは上からくる影に敏感なので、鳥に襲われる動きと重なってしまいます。顔の高さまで手を低く持ってきて、鼻先に指を見せてから額へ回すと、驚かせずに済みます。

うちのうさぎも、お迎えから2か月ほどは上から手を出すたびに頭を下げて避けていました。床に手をついて鼻先から入るやり方に変えてから、逃げることはほとんどなくなりました。

### 鼻の付け根とほほ


![](/assets/img/rabbit-12/hoho.jpg)


**鼻筋は一度覚えると目を細める子が多い場所です**

鼻の付け根は、おでこに次いで反応がよい部分です。指1本の腹で、鼻先から額に向かって短くなぞります。往復させるより、同じ方向に3〜4回のほうが落ち着いてくれます。

ほほは、ひげの生えぎわを避けて、耳のほうへ向かって。ひげに触ると顔を引く子が多いので、そこだけずらすと嫌がり方が減ります。口元まで指が近づくと噛まれることもあるため、牧草を食べているあいだは手を出さないほうが無難です。

### 耳の付け根


![](/assets/img/rabbit-12/mimi.jpg)


**耳の後ろは仲間が毛づくろいし合う場所です**

頭と耳のつながるあたりは、うさぎ同士でもなめ合う場所。ここを撫でると、あごを床につけて体を伸ばす子がいます。==耳そのものはつかまない==でください。血管が通っていて熱の出入りを調整している部分なので、強く握ると負担になります。

ロップイヤーのように耳が垂れている子は、付け根に汚れがたまりやすいところ。撫でるついでに、赤みや耳あかのにおいを確かめておくと早めに気づけます。

### 背中は前半分まで

**背中は肩から腰の手前までにとどめます**

背中は、首の後ろから肩甲骨あたりまでなら受け入れる子が多いです。手を止めずに、ゆっくり一方向へ。腰からおしりに近づくにつれて、嫌がる子の割合が増えていきます。

腰の上を触られると、交尾のときに押さえられる感覚に近いためか、急に体を回して振り向くことがあります。発情期に入っている子だと、そのまま噛みついてくることも。背中は腰の手前で手を離す、と決めておくと行き違いが起きません。

うさぎのしぐさ全体の読み取り方は{{link:rabbit-behavior|うさぎのしぐさの意味}}にまとめています。

## 触られたくない部位は、身を守る場所に集まっています

嫌がる部位には共通点があります。==つかまれたら逃げられない場所==と、自分で毛づくろいできる場所です。

おなかは、野生では地面につけて隠している部分です。仰向けにすると動けなくなる子がいますが、これは安心しているのではなく、身をすくめている状態に近いと考えられています。抱っこのついでに仰向けにするのは避けたいところ。抱き方は{{link:rabbit-holding|うさぎの抱っこの仕方}}で紹介しています。

おしり・しっぽ・後ろ足は、捕食者に押さえられる場所です。足先に手が触れた瞬間に蹴って逃げる子も多いですよ。爪切りや足裏の確認で触る必要はありますが、撫でる目的では近づかないほうが関係がこじれません。

あご下は、好みが大きく分かれます。あごには臭腺があり、うさぎは自分でこすりつけてにおいを付けています。そこを人の手でなでられると、嫌う子と、そのままあごを乗せてくる子に分かれるところです。

## 気持ちいいときと、やめてほしいとき

撫でている最中のサインは、はっきり出ます。ここだけ覚えておけば、やりすぎを防げます。

| しぐさ | 読み取れること |
|---|---|
| 目を半分閉じる・あごを床につける | 心地よい |
| 小さくカチカチと歯を鳴らす | 満足している |
| 手の下に頭を押しつける | もっと撫でてほしい |
| 鼻でツンと押してくる・頭を振る | もう十分 |
| 耳を後ろに倒して低く構える | 不快・警戒 |
| 足で床を強く踏む | はっきりとした拒否 |
| 大きくギリギリと歯を鳴らす | 痛みの可能性 |

まぎらわしいのは歯の音です。軽くカチカチと小さく鳴るのは満足しているときの音で、猫がのどを鳴らすのに近いもの。これに対して、==動かずに大きくギリギリと鳴らす==ときは痛みを我慢している場面があります。食欲やうんちの量も落ちていれば、様子を見るより先に動物病院へ。

鼻でツンと押してきたら、そこで一度手を止めます。1回の撫でる時間は3〜5分を目安に、嫌がるサインが出たら10秒ほどで手を引くと、次も寄ってきてくれます。

## 撫でると逃げる子に、手を覚えてもらう順番

逃げる子には、触る場所を増やす前に、手の高さを変えるほうが効きます。追いかけて撫でるのをやめるのが出発点です。

床に座って、手を床につけたまま動かさずに待ちます。向こうから鼻を近づけてにおいを確かめたら、そのまま額に指を回す。この一連を、1日2回ほど、2週間くらいかけて繰り返します。

順番としては、鼻先のにおい確認 → おでこ → ほほ → 耳の付け根 → 背中の前半分。1段階ごとに数日あけて、前の段階で逃げなくなってから次へ進めると失敗が少ないです。

お迎え直後は、この手前の段階から始めることになります。最初の1週間は触らずに環境に慣れてもらう時期なので、{{link:rabbit-first-week|うさぎのお迎え初日は何をする？}}も見てみてください。

## 換毛期に撫でるときは、抜け毛も一緒に

換毛期は、撫でた手に毛がびっしり付く時期です。ここで==手で撫でるだけで抜け毛が取れる==形にしておくと、撫でる時間がそのまま毛のケアになります。

手袋型なので、ブラシを見せると逃げてしまう子にも、いつもの撫で方のまま使えます。指先まで覆われていて、おでこから背中へ流す動きで浮いた毛を拾ってくれるタイプ。嫌がる子への慣らし方や、ほかの形との違いは別の記事にまとめています。

撫でながら毛を取っておきたいのは、うさぎが自分で毛づくろいをするときに抜け毛を飲み込むためです。うさぎは吐き出せないので、換毛期は飲み込む量が増えます。食欲が落ちた、うんちが小さくなった、数が減ったというときは、自己判断せず動物病院で相談しましょう。

## 急に嫌がるようになったときの目安

これまで平気だった部位を触ると避けるようになったときは、好みが変わったのではなく、そこが痛いことがあります。触られ方の変化は、体調の変化より先に出る場面があるんですね。

| 変化のしかた | 考えられること |
|---|---|
| 背中や腰を触ると逃げる | 背中や関節の痛み |
| あご下を触ると顔を引く | 歯のトラブル・しこり |
| 耳に触ると頭を振る | 耳の中の炎症 |
| 全身どこでも避ける・じっとして動かない | 体調の低下 |
| 撫でた手に毛がかたまりで付く | 皮膚の荒れ |

目安としては、==半日以上えさに口をつけない==、あるいはうんちが半分以下に減ったときは、その日のうちに相談したいところ。うさぎは1日食べないだけで体力が落ちるので、迷う時間を長く取らないほうがよいでしょう。

撫でる時間は、体を確かめる時間にもなります。週に1回は、あご下のしこり・背中の毛のかたまり・おしりの汚れ・足裏の毛の薄さを、撫でる流れで見ておくと変化に気づきやすいです。見る場所の全体は{{link:rabbit-health-check|うさぎの健康チェックと健康診断}}にまとめました。

## よくある質問

### 撫でるのはいつから始められますか

お迎えから1週間ほどは環境に慣れる時期なので、無理に触らないほうが落ち着きます。ケージから自分で出てきて、人のそばで伸びるようになってからが始めやすいタイミング。それでも寄ってこない子は、手を床に置いて待つところから少しずつ進めてみてください。

### 1日にどのくらい撫でていいですか

1回3〜5分を1日2回くらいが目安です。長さより、嫌がる前に切り上げることのほうが効きます。自分から頭を押しつけてくるときは、その分だけ延ばしても構いません。

### 撫でていると噛まれるのはなぜですか

手を止めたときや、腰のあたりを触ったときに噛んでくる子がいます。やめてほしいという合図か、もっと撫でてという要求のどちらかが多いです。噛み方の見分け方と対応は{{link:rabbit-biting-people|うさぎが人を噛む理由}}で紹介しています。

### あご下を撫でるのは避けたほうがいいですか

嫌う子は多いものの、全部の子が苦手というわけではありません。指1本で軽く触って、顔を引かなければ続けて大丈夫です。顔を引く、頭を振るといった動きが出たら、その日はやめておきましょう。

## 手が届く場所から仲良くなろう

うさぎが撫でられて心地よい部位と、嫌がる部位について紹介しました。おでこ・鼻の付け根・耳の付け根は自分で毛づくろいできない場所で、おしり・おなか・足先は身を守る場所。手は上からではなく、顔の高さから鼻先に見せてから回すと受け入れられやすくなります。きょうは額を指2本でなぞるところから、試してみてください。
