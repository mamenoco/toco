# うさぎがなめるのはなぜ？手・服・床をなめる理由と気をつけたいこと

部屋んぽ中に足元まで来て、手の甲をぺろぺろ。かわいいなと眺めていたら、今度はフローリングを延々となめ始めて、やめる気配がない。このままなめさせていて平気なのか、気になってしまいますよね。うさぎがなめるのは==仲間同士の毛づくろいと同じしぐさ==で、心配のいらない場面がほとんどです。ただし、同じ一か所を10分以上なめ続けるときや、なめたあとに食欲が落ちているときは、別の理由を考えることになります。

この記事では、うさぎがなめてくる場面と、手・服・床・布・ケージという場所ごとの理由をまとめました。やめてほしいときにできることと、動物病院に相談する目安もあわせて紹介します。

## うさぎがなめるのは毛づくろいの延長です

うさぎが人をなめるのは、==仲間同士でおこなう毛づくろいの延長==です。群れで暮らす動物なので、相手の顔やまわりを互いになめ合って、同じ群れの一員だと確かめ合います。人の手や顔も、その相手の一つに入っているわけですね。

なめてくるタイミングは、だいたい決まっています。なでている手を止めたとき、膝に乗っているとき、ケージに戻る直前。どれも体が落ち着いて、警戒がゆるんでいる場面です。

反対に、鼻先でツンと押してきたり、歯を当ててきたりするのは別の合図。なめるのとは意味が変わるので、{{link:rabbit-behavior|うさぎのしぐさの意味}}もあわせて見てみてください。

## なめる場所でわかる、それぞれの理由

なめている場所を見ると、理由はかなり絞れます。まずは早見表で全体を確かめてみてください。

| なめる場所 | 多い理由 | 気をつけたいこと |
|---|---|---|
| 手・顔 | 親愛・汗やにおい | クリームや消毒剤の付いた手 |
| 服の袖・裾 | 洗剤のにおい・甘え | 糸をかじって飲み込む |
| 床・フローリング | 塩分やミネラル・退屈 | ワックスや洗剤の残り |
| カーペット・布 | 毛づくろいの延長 | 繊維の飲み込み |
| ケージの金網 | 出してほしい要求 | 歯への負担・塗装はがれ |

### 手や顔をなめる

**においと味に引かれてなめている面もあります**

手の甲や指先をなめるのは、==毛づくろいのお返しに近い動き==です。そこに汗の塩分や食べ物のにおいが乗ると、なめる時間が長くなります。顔に来る子は、口のまわりや髪の生え際を選ぶことが多いですよ。

気をつけたいのは、ハンドクリームや消毒液、アロマオイルが付いた手です。うさぎは体が小さいぶん、人にとって少量のものでも負担になることがあります。塗ったあとは手を洗うか、30分ほどあけてから触るようにしてみてください。

化粧品や日焼け止めも同じで、なめられる場所に残っていると避けようがありません。顔を近づけるのは、スキンケアの前にしておくと気がラクです。なめて危ないものは{{link:rabbit-nogo-food|うさぎが食べてはいけないもの一覧}}にもまとめています。

### 服の袖やズボンをなめる

**服には洗剤や柔軟剤のにおいが残っています**

部屋んぽ中にズボンの裾をなめたり、膝に乗ったまま袖をなめ続けたり。服をなめるのは、人のにおいと洗剤のにおいが混ざった場所に反応しているからです。==体を預けた姿勢でなめているなら、落ち着いているサイン==と見ていいでしょう。

困るのは、なめるから噛むに移ったときです。ニットやフリースは糸を引き出しやすく、飲み込んだ繊維はうさぎの力では吐き出せません。毛足のある服は、部屋んぽの時間だけ着替えておくと安心ですね。

### 床やフローリングをなめる

**床なめは味と退屈の両方が重なって起こります**

フローリングには、こぼれた飲み物や足裏の汗、掃除に使った洗剤が薄く残ります。塩分やミネラルのにおいをたどってなめている子が多いです。部屋んぽの時間が短い日ほど、同じ場所を長くなめる傾向もあります。

フローリング用のワックスや洗剤は、うさぎがなめることを前提に作られていません。部屋んぽをさせる範囲は水拭きだけにしておくほうが、こちらも気をもまずに済みます。

わが家でも、部屋んぽのたびに窓際の同じ一角をなめるので、その範囲だけ洗剤をやめて水拭きに切り替えました。半年ほど続けていますが、なめる時間は以前より短くなっています。

### カーペットやソファの布をなめる

**布は繊維が口に入りやすいので早めに切り上げたい場所です**

毛足のあるカーペットやソファカバーは、なめているうちに繊維が少しずつ口に入ります。少量なら便と一緒に出ていきますが、量がたまるとお腹の動きが落ちることもあります。

重なりやすいのは換毛期です。飲み込む毛が増える時期に布の繊維まで入ると、お腹への負担が大きくなります。食欲が落ちた、うんちが小さくなった、数が減ったというときは、様子を見るより先に動物病院へ。

### ケージの金網をなめる

**金網なめは出してほしいという要求のことが多いです**

部屋んぽの時間が近づくと金網をなめたり噛んだりする子は、==音を立てれば人が来る==と覚えています。そのたびに出していると、だんだん激しくなっていきます。

塗装がはがれた金網をなめ続けると、歯の先が削れてかみ合わせが変わることも。前歯の伸び方が左右で違ってきたときは、早めに診てもらいたいところです。見方は{{link:rabbit-teeth|うさぎの不正咬合とは？}}で紹介しています。

うちのうさぎも、部屋んぽ前の30分だけ金網をなめます。出す時刻を夜8時に固定してからは、それより前になめることはほとんどなくなりました。

## なめるのをやめてほしいときにできること

叱るより、なめたくなる理由を一つずつ減らすほうが早く収まります。うさぎは数秒前の行動と叱られたことを結びつけられないので、伝わるのは怖さだけなんですね。

- 要求でなめているときは、その場で反応せず、少し間をおいてから出す
- 部屋んぽの範囲は水拭き中心にして、洗剤やワックスを残さない
- なめられたくない布やクッションは、部屋んぽのあいだだけ片付ける
- 手を洗ってから触る。クリームを塗った直後は近づけない
- 部屋んぽを1日30分以上、朝と夜の2回に分けて確保する

退屈からくるなめ方には、かじってよいものを別に用意しておくのが効きます。金網やカーペットに向かっていた口が、そちらに移ってくれることがありますよ。

それでも同じ場所をなめ続けるなら、ケージの置き場所も見直してみてください。人の通り道に面していたり、テレビの音が近かったりすると、落ち着けないまま同じ動きを繰り返すことがあります。

## 病院で相談したいなめ方

なめ方が急に変わったときと、体の一部だけをなめ続けるときは、相談しておくほうが安心です。目安は次のとおりです。

| こんななめ方 | 考えられること |
|---|---|
| 同じ一か所を毎日10分以上 | ストレス・退屈 |
| なめた場所の毛が薄い・皮膚が赤い | 皮膚の炎症 |
| 足の付け根や後ろ足ばかり | 痛みや足裏の荒れ |
| よだれで口のまわりが濡れる | 歯のトラブル |
| 布を飲み込んだあと食欲が落ちた | お腹の動きの低下 |

後ろ足の裏を気にしてなめるときは、毛の薄さや赤みを確かめてみてください。進み方には段階があるので、{{link:rabbit-sorehock|うさぎのソアホックとは？}}で早い段階のサインを知っておくと役に立ちます。

布や糸を飲み込んだ疑いがあるときは、食欲とうんちを半日ごとに見ます。うさぎは丸1日食べないだけでも体力が落ちるので、迷う時間を長く取らないほうがよいでしょう。気になる症状があるときは、自己判断せず動物病院で相談しましょう。

## よくある質問

### なめるのはなついているサインですか

落ち着いた姿勢でなめているなら、仲間として扱われている合図と考えていいでしょう。ただ、においに引かれてなめているだけのこともあるので、なめる回数だけで仲の良さは測れません。距離の縮め方は{{link:rabbit-bonding|うさぎはなつく？}}にまとめました。

### なめさせたままで、人の側に害はありませんか

健康なうさぎに手をなめられるぶんには、心配しすぎなくて大丈夫です。気になるときは、なめられたあとに手を洗っておくと安心。傷口や絆創膏の上はなめさせないようにしておきたいところです。

### 急になめなくなったのはなぜですか

発情や季節の変わり目で、人への関わり方が一時的に変わることがあります。食欲とうんちが変わらないなら、しばらく様子を見て構いません。食べる量が落ちている、じっとして動かないといった変化が重なるときは、動物病院で相談しましょう。

## なめる場所から気持ちを読み取ろう

うさぎがなめる理由と、場所ごとの見方について紹介しました。手や服は毛づくろいと甘えの延長、床や布は味と退屈、金網は出してほしい要求。どこをなめているかが分かれば、そのままにしておく場面と、理由を減らしてあげる場面を分けられます。きょうの部屋んぽで、どこをなめていたか見てみてください。
