# うさぎと旅行・帰省はどうする？ペットホテルと留守番の決め方

※本記事にはアフィリエイト広告が含まれます。

旅行や帰省の日程が決まったあとで、うさぎをどうするかだけが決まらない。連れていくのも置いていくのも不安で、調べるほど迷ってしまいますよね。線引きはわりとはっきりしていて、==1泊までは家で留守番、2泊からは預ける==と考えておけば大きく外れません。移動そのものがうさぎには負担になるので、連れていくのは最後に残る選択肢です。

この記事では、留守番で足りる日数の目安、ペットホテル・動物病院・うさぎ専門店・ペットシッターという預け先の違い、予約の前に確かめておく5つのこと、どうしても連れていくときの移動のしかたまでまとめました。帰省のように毎年ある予定ほど、預け先を先に決めておくと直前で慌てずに済みます。

## 1泊までは家で留守番、2泊からは預けます

決め手になるのは、家を空ける長さです。丸1日くらいなら、牧草と水を用意しておけばうさぎは家で過ごせます。2日目からは、水の飲み口が詰まる・トイレが汚れたままになる・空調が止まるといったことが起きても、気づく人が家にいません。

| 家を空ける長さ | 選ぶ形 |
|---|---|
| 日中だけ（〜10時間） | 留守番。牧草と水を2か所に分ける |
| 1泊（〜24時間） | 留守番。朝に1日分を入れてから出る |
| 2泊 | 預けるか、家に来てもらう |
| 3泊以上 | 預ける。家には置かない |

1泊で留守番させるなら、出発前にやることは3つです。牧草を牧草入れと床置きのボウルの2か所に入れる、水をボトルと食器の両方に用意する、トイレを掃除してから出る。==片方が止まっても、もう片方で足りる形==にしておくのがポイントですよ。

夏と冬は、空調をつけたまま出るのが前提になります。やむを得ず家を空けるときは、えさと水の確保や温度の管理に配慮するよう、家庭で飼う動物の飼養の基準にも示されています（参考：環境省）。

日中の留守番の過ごし方は{{link:rabbit-alone-living|一人暮らしでうさぎは飼える？}}でも詳しく書いています。

## うさぎの預け先は4つから選びます

預け先は、小動物を扱うペットホテル・かかりつけの動物病院・うさぎ専門店の預かり・自宅に来てもらうペットシッターの4つです。どれが正解ということはなく、うさぎの年齢と体調、それに留守の長さで向き不向きが分かれます。

| 預け先 | 得意なところ | 向いている場面 |
|---|---|---|
| ペットホテル | 空きが見つけやすい | 元気な成うさぎ・2〜3泊 |
| 動物病院 | 体調の変化に気づける | 高齢・持病・投薬がある |
| うさぎ専門店 | 扱いに慣れている | 長めの帰省・初めての預け |
| ペットシッター | 移動させずに済む | 環境が変わると食べない子 |

犬や猫と違って、うさぎはどこでも預かってもらえるわけではありません。ペット可とうたっていても、受け入れるのは犬と猫だけという施設は多いです。小動物対応と書いてあっても、ハムスターは可でうさぎは不可ということもあるので、ホームページだけで判断せず電話で確かめておきたいところ。

ペットシッターは、うさぎを動かさずに済むのがいちばんの持ち味です。ただ、人が来るのは1日1〜2回なので、その間に起きたことには気づけません。==体調に不安がある子なら、動物病院の預かりを先に当たる==ほうが安心して出かけられます。

うさぎを診られる病院の探し方は{{link:rabbit-vet|うさぎの動物病院の探し方}}にまとめました。

## ペットホテルを予約する前に確かめる5つのこと

うさぎのペットホテル選びは、きれいさや料金よりも、うさぎの扱いに慣れているかどうかで決まります。電話で確かめるのは、次の5つです。

- うさぎを預かった経験があるか
- 犬や猫と別の部屋になるか
- 牧草とペレットを持ち込めるか
- 部屋の温度と湿度をどう管理しているか
- 食欲が落ちたときに連絡がもらえるか

### うさぎを預かった経験があるか

**うさぎの宿泊を受け入れた実績があるかを先に聞きます**

同じ小動物でも、うさぎは食べない時間が続くと体調が傾きやすい動物です。牧草をどれくらい入れるか、便の大きさをどこで見るかを知っている人に預けたいところ。

月に何羽くらい預かっているかを聞くと、慣れているかどうかが見えてきます。年に数回という答えなら、うさぎ専門店や動物病院のほうを当たってみてください。

### 犬や猫と別の部屋になるか

**うさぎは犬や猫の気配だけでも落ち着かなくなります**

うさぎは捕食される側の動物なので、吠え声やにおいがあるだけで緊張が続きます。食べない・動かないという状態になると、預けている間に体調を崩すきっかけになります。

小動物専用の部屋があるか、せめて犬猫と階やフロアが分かれているかを確かめておきましょう。ケージの置き場所まで指定できる施設もありますよ。

### 牧草とペレットを持ち込めるか

**いつも食べているものを持ち込めるところを選びます**

うさぎは食べ慣れないものを急に出されても口をつけないことがあります。施設の用意する牧草に切り替わるだけで、食べる量が落ちることも。

持ち込み可の施設なら、==泊数より1日多いぶん==を小分けにして渡しておくと足ります。延泊になったときにも困りません。

牧草を分けて持っていくときは、密閉できる容器に入れておくと湿気を吸いません。入れ物の選び方は{{link:rabbit-hay-storage|うさぎの牧草の保存容器のおすすめ}}で紹介しています。

### 部屋の温度と湿度をどう管理しているか

**目安は室温20〜25℃／湿度40〜60%です**

うさぎは汗をかけないので、暑さには犬や猫よりずっと弱い動物です。夏に預けるなら、空調が24時間動いているかを確かめておきたいところ。

夜間や休館日に空調を落とす施設もあります。何時から何時まで入れているかまで聞いておくと、返事があいまいなところを外せますよ。

### 食欲が落ちたときに連絡がもらえるか

**食べない時間が続いたときの連絡の約束を決めておきます**

半日ほど食べていない状態が続くと、消化管の動きが落ちることがあるとされています。預けている間にそうなったとき、誰がどこへ連れていくのかを先に決めておくと動けます。

かかりつけの病院名と連絡先、それに自分の連絡先を書いた紙を1枚添えておくのがおすすめです。提携している動物病院があるかどうかも、あわせて聞いておきましょう。

宿泊料のほかに、暖房費・食事代・投薬代が別で加算される施設もあります。合計でいくらになるかは、予約のときに確かめておくと会計で驚きません。

## 旅行や帰省に連れていくときの移動のしかた

連れていくかどうかは、片道の移動時間で決めます。==片道2時間を超えるなら、預けるほうを先に検討==してみてください。知らない場所に着くことより、揺れと音が続く移動のほうがうさぎにはこたえます。

車なら、キャリーは助手席ではなく後部座席の足元に置きます。直射日光が当たらず、急ブレーキでも動かない場所だからです。2時間ごとに休憩を取って、水を飲むかと呼吸が速くなっていないかを見ておきましょう。

電車は、JRの場合、長さ70cm以内でタテ・ヨコ・高さの合計が90cm程度のケースに入れ、動物とケースを合わせて10kg以内であれば、手回り品のきっぷを買って持ち込めます（参考：JR東日本）。私鉄やバスは会社ごとに決まりが違うので、乗る路線の規定を先に見ておくと当日もたつきません。

飛行機は、うさぎを預かるかどうかが航空会社によって分かれます。夏場は受付を止める期間もあるので、航空券を取る前に問い合わせておくほうが確実。帰省先に着いてからも、ケージ・牧草・トイレを一式そろえることになるので、荷物はそれなりの量になります。

移動に使うキャリーは、底が平らで中で滑らないものが向いています。選び方は{{link:rabbit-carry|うさぎのキャリーバッグのおすすめ}}で紹介しているので、通院用とまとめて考えてみてください。

## 預ける前の準備と当日の持ち物

準備は当日ではなく、1〜2か月前から始まります。夏休み・年末年始・ゴールデンウィークは、うさぎを受け入れる施設から先に埋まっていくためです。

| いつ | すること |
|---|---|
| 1〜2か月前 | 予約を入れる。長期休みはとくに早めに |
| 1週間前 | 食欲・便の大きさ・体重を見ておく |
| 3日前 | 持たせる牧草とペレットを小分けにする |
| 前日 | キャリーを部屋に出して慣らす |
| 当日 | トイレを掃除してから入れる |

当日に持っていくのは、いつもの牧草とペレット（泊数＋1日分）・かじり木やおもちゃなど使い慣れたもの・飲み慣れた水・かかりつけの病院の連絡先です。薬を飲んでいる子は、1回分ずつ分けて日付を書いておくと間違いが起きません。

出発前の1週間は、体調を見ておく期間でもあります。便が小さくなっている、食べる量が落ちている、じっとして動かない。こうした様子があるときは、預ける予定を変えることも考えてみてください。気になる症状があるときは、自己判断せず動物病院で相談しましょう。

うっ滞のサインと見分け方は{{link:rabbit-stasis|うさぎのうっ滞とは？}}にまとめています。

## よくある質問

### ペットホテルの予約はいつまでに取ればいいですか

うさぎを受け入れる施設は数が限られるので、長期休みなら1〜2か月前が目安です。夏休みと年末年始は、2か月前でも埋まっていることがあります。帰省の予定が毎年同じ時期なら、前回の帰りに次の予約を押さえてしまう方もいますよ。

### 子うさぎやシニアのうさぎも預けられますか

生後3〜4か月くらいまでの子うさぎと、7歳を過ぎたうさぎは、断られることがあります。環境が変わったときの体調の振れ幅が大きいためです。この年代は、ペットホテルより動物病院の預かりを先に当たるほうが見つかりやすいです。

### 預けている間に食べなくなったと連絡が来たら、どうすればいいですか

その場で動物病院へ連れていってもらえるかを確かめて、かかりつけの連絡先を伝えてください。半日ほど食べていない状態は、様子を見る段階ではなくなっています。預ける前に、こうなったときはどうするかを施設と決めておくと、電話口で迷わずに済みます。

## 預け先を決めてから、旅行の予定を立てよう

うさぎがいる暮らしで旅行や帰省のときにつまずくのは、日数の判断より、預け先が見つからないことのほうです。1泊までは家で留守番、2泊からは預ける。この線引きだけ持っておけば、あとは預け先を探す話になります。

ペットホテル・動物病院・うさぎ専門店・ペットシッターのうち、うちのうさぎならどこかを、出かける予定のないうちに一度調べておきましょう。電話で5つ確かめて、1か所でも受け入れてくれるところが分かっていれば、次の旅行の予定はずっと立てやすくなります。
