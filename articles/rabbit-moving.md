# うさぎの引っ越しはストレス？移動当日と新居に慣れる7日間

※本記事にはアフィリエイト広告が含まれます。

引っ越しの日取りが決まったあと、うさぎをどう連れていくかで手が止まってしまいますよね。搬出の最中にケージを置ける部屋がない、移動に何時間もかかる、着いてから食べなくなったら頼れる病院もない。負担が大きいのは、車に乗っている時間そのものより、==着いた先で部屋の景色もにおいもまとめて入れ替わること==です。当日は短く静かに運んで、新居ではケージの中を前の家と同じ配置に戻す。この2つで、落ち着くまでの日数が変わってきます。

この記事では、引っ越し前の2週間でしておくこと、当日の運び方と車の中で気をつけたいこと、着いてからの7日間の過ごし方、それに様子を見ていい変化と病院に行く目安をまとめます。移動まで日がないなら、当日の進め方から読んでみてください。

## うさぎの引っ越しは、移動よりも着いたあとが負担になります

うさぎの様子が変わるのは、移動している数時間より、新しい部屋で過ごす最初の数日です。音・におい・光の入り方が一度に変わるので、隅でじっとして出てこない時間が長くなります。

==落ち着くまでの目安は3〜7日==ほど。もともと物音に敏感な子だと、2週間かけてゆっくり戻っていくこともあります。

| 様子 | よく出る時期 | すること |
|---|---|---|
| 隅で動かない | 当日〜2日目 | 声をかけるだけで触らない |
| 牧草を残す | 当日〜3日目 | 前の家と同じ銘柄を続ける |
| トイレを外す | 2日目〜1週間 | 使っていたシーツを1枚入れる |
| 水を飲む量が減る | 当日から | 給水器の高さを元に戻す |
| うんちが少し小さい | 当日〜2日目 | 48時間で戻るかを見る |

この表に入っていない変化、たとえばおなかを床につけて動かない・歯ぎしりが続くといった様子は、様子見の範囲から外れます。見分け方はあとの「様子を見ていい変化と、病院に行く目安」でまとめます。

部屋の中でケージの位置を変えるだけでも、うさぎには景色が入れ替わる出来事です。わが家でも、お迎えから半年でテレビの横からリビングの隅へケージを移しました。

## 引っ越し前の2週間でしておくこと

前の家でできる準備は、==キャリーに慣らすことと、えさを切らさないようにしておくこと==の2つです。どちらも当日になってからでは間に合いません。

キャリーは、2週間前からケージの横に置いて、扉を開けたままにしておきます。中に牧草をひとつかみ入れておくと、自分から入る子もいますよ。入るようになったら1日5分だけ扉を閉めて、家の中を少し歩いてみる。この順番で進めると、当日の出発でいきなり押し込むことにならずに済みます。

{{product:chanet-2127}}

うさぎ用に作られた布製のおでかけバッグです。練習用と当日用を分けずに済むので、2週間前から同じバッグで慣らしていけます。やわらかいタイプは体が揺れやすいため、車では座席の足元に置いて動かないようにしておきたいところ。

{{card:rabbit-carry}}

牧草とペレットは、==引っ越しをはさんで2週間ぶん残る==ように買っておきます。新居で銘柄を変えると、環境と食事が同時に変わって、食べない原因がどちらなのか分からなくなります。トイレ砂やシーツも、同じものを使い切るまで変えないでおきましょう。

ペット可の物件でも、うさぎは種類の欄に入っていなくて確認が必要になることがあります。契約前に見ておきたいところは{{link:rabbit-rental|賃貸でうさぎは飼える？}}にまとめました。

## 移動当日は、最後に運んで最初に迎える

当日のうさぎは、荷物の搬出が終わったあとに最後に運び出して、==新居ではいちばん先にケージを組む==のがいちばん静かに済みます。段ボールの出入りと同じ部屋で待たせると、ドアの開け閉めと足音が何時間も続いてしまいます。

| 時間 | うさぎ | 人 |
|---|---|---|
| 出発の3時間前 | ペレットは半分にしておく | ケージはそのまま |
| 搬出中 | 別室かキャリーで静かに待つ | ドアを閉めておく |
| 出発 | 牧草をひとつかみ入れて移す | 車内を25度以下に |
| 移動中 | 2時間ごとに水をすすめる | 直射日光を当てない |
| 到着 | ケージを組んでから中へ | 荷ほどきは後まわし |

車で運ぶときは、キャリーを座席の上ではなく足元に置いて、動かないようにします。エアコンの風が直接当たる位置は外しておきたいところ。==夏場は車内が30度を超えるので、停車中にうさぎだけを残さない==のがいちばん大事です。

電車や飛行機を使う場合は、ケースの大きさや重さの決まりが会社ごとに違います。飛行機は時期によって預かりを受けられないこともあるので、日程が決まった時点で問い合わせておくと安心です。

水は、移動が2時間を超えるなら一度すすめてみます。飲まなくても、口のまわりが湿るだけで落ち着く子もいます。

{{product:naocyame-2084}}

移動の途中でも水をすすめられる、持ち歩き用のボトルです。ケージの給水器を先に外して荷物へ積んでしまったあとでも、休憩のたびに少しずつ飲ませられます。ステンレス製で、荷物の中に入れたまま持ち運びやすい形。

{{card:bottle}}

当日ひとまとめにしておきたい中身は、災害時の持ち出し袋とほとんど同じです。そろえ方は{{link:rabbit-emergency-kit|うさぎの防災対策}}で紹介しています。

## 新居に着いてからの7日間

着いてから3日はケージの中だけで過ごしてもらって、部屋んぽは4日目以降に戻します。歩ける範囲が一気に広がると、隠れる場所を探すのに時間を使ってしまうためです。

| 日 | すること | 見るところ |
|---|---|---|
| 当日 | ケージを元の配置で組む | 水を飲むか |
| 1〜2日目 | 声をかけるだけ・触らない | うんちの数と大きさ |
| 3日目 | 掃除を普段のやり方に戻す | 食べる量 |
| 4〜5日目 | 10分ほどの部屋んぽから再開 | 自分で戻れるか |
| 6〜7日目 | 起きる時間・あげる時間を元に | トイレの場所 |

ケージは、==中の配置を前の家とそろえる==のがこつです。トイレ・牧草入れ・給水器の位置が同じなら、外の景色だけが変わった状態になります。引っ越し前に大掃除をしたくなりますが、丸洗いは落ち着いてからにして、においが残ったまま運んでしまいましょう。

置き場所は、窓とエアコンと通路から距離を取った壁ぎわが第一候補になります。新しい部屋で決めかねるときは、{{link:rabbit-cage-4|うさぎのケージの置き場所はどこがいい？}}の5つの条件から当てはめてみてください。

ケージを買い替えるなら、引っ越しから2週間は空けます。住む場所と寝床が同じ日に変わると、トイレの場所を覚え直すところからやり直しになることもあるからです。サイズの選び方は{{link:rabbit-cage|うさぎのケージのおすすめ}}で紹介しています。

## 様子を見ていい変化と、病院に行く目安

分かれ目は、うんちと食欲が12時間で動いているかどうかです。引っ越しのあとに起こりやすいのは、食べる量が落ちておなかの動きが止まってしまう{{link:rabbit-stasis|うっ滞}}で、半日の変化を見ておくと気づけます。

| 見るところ | 様子を見ていい | 受診を考える |
|---|---|---|
| うんち | 少し減って1〜2日で戻る | 12時間出ていない・急に小さい |
| 食欲 | ペレットは残すが牧草は食べる | 12時間どちらも口にしない |
| 姿勢 | 隅でじっとしている | おなかを床につけて動かない |
| 呼吸 | 移動の直後だけ速い | 口を開けて呼吸している |
| 鼻・目 | – | 鼻水やくしゃみが続く |

到着から48時間は、うんちの数と大きさを毎日見ておきます。小さいうんちが続くときは、牧草を食べる量が落ちているサインなので、食べ慣れたおやつでも口にするかを確かめてみてください。

新居の近くでうさぎを診てもらえる病院は、引っ越す前に1件決めておきます。夜間や休日に動ける範囲かどうかまで見ておくと、いざというときに迷いません。探し方は{{link:rabbit-vet|うさぎの動物病院の探し方}}にまとめています。気になる症状があるときは、自己判断せず動物病院で相談しましょう。

## よくある質問

### 引っ越しのストレスはどのくらいで落ち着きますか

多くは3〜7日ほどで、食べる量とうんちが元に戻ってきます。物音に敏感な子だと2週間かかることもあるので、1週間で完全に戻らなくても心配しすぎなくて大丈夫です。ただし食欲が12時間以上落ちたままの場合は、慣れの問題ではないので病院で相談しましょう。

### 移動中にごはんや水はあげたほうがいいですか

牧草はキャリーに入れておいて、好きなときに食べられるようにしておきます。水は移動が2時間を超えるなら一度すすめる形で十分で、飲まなくても問題ありません。ペレットや野菜は車の中では控えて、新居に着いてから普段の時間に戻しましょう。

### お迎えしてすぐの引っ越しでも大丈夫ですか

できれば、お迎えから2週間は動かさずに過ごしたいところ。日程をずらせないなら、新居で触らない期間をもう一度取り直す形になります。最初の1週間の過ごし方は{{link:rabbit-first-week|うさぎのお迎え初日は何をする？}}で紹介しているので、あわせて読んでみてください。

## 静かに運んで、同じ配置で迎えよう

うさぎとの引っ越しは、当日を短く静かに終わらせて、新居ではケージの中を前の家と同じに戻す。この2つが決まっていれば、あとは3日ほど待つだけです。

部屋んぽは4日目から、ケージの買い替えは2週間後から。うんちと食べる量だけは毎日見ておいて、12時間動かないときは病院へ。新しい部屋でも、同じにおいの寝床があればうさぎは戻ってきてくれます。
